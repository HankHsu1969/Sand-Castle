# 沙堡物語 · Sandcastle Dreams

一款在熱帶沙灘上堆沙、築牆、挖護城河，並用城堡迎接潮汐的放鬆 3D 遊戲（Three.js）。

## 執行

```bash
npm install
npm run dev
```

開啟 http://localhost:5199 即可遊玩。`npm run build` 會輸出到 `dist/`（需用 `npm run preview` 或任何靜態伺服器開啟）。

## 玩法

| 操作 | 說明 |
|---|---|
| 左鍵 | 使用工具（堆沙、挖沙、抹順、壓平、水桶塔、城牆、挖渠、裝飾、旗幟） |
| 右鍵拖曳 / Shift+右鍵 | 旋轉 / 平移視角 |
| 滾輪、WASD、Q/E | 縮放、移動、旋轉 |
| 1–9、`[` `]` | 切換工具、調整筆刷 |
| Ctrl+Z、T、H、Esc | 復原、迎接漲潮、說明、暫停 |

五個關卡：晨曦海灣 → 珊瑚潟湖 → 棕櫚小島 → 沙洲屏障 → 夕陽三角洲。進度與寶藏圖鑑存在瀏覽器 localStorage。

> 測試版：目前五關全部解鎖（`src/game/Game.js` 的 `UNLOCK_ALL_LEVELS`）。

## 技術重點

- 320×320 可雕塑沙地高度場 + 160×160 淺水「虛擬管線」流體模擬（潮汐、成組的碎浪、浪花、河流、水道引水）
- 半透明海水：看得到魚群、海龜、魟魚、水母、海帶、海膽、海星與珊瑚；遠方有海豚跳躍
- 海浪侵蝕：水流會讓陡峭的沙子坍塌、城堡慢慢融化
- 自製沙子材質（三平面投影、濕沙變深、水下焦散）、海洋著色、天空大氣、移軸微縮後製
- 每關地標：木棧橋、燈塔、茅草小屋、水上屋、小船、火把；18 種可擺放裝飾（含可貼在城牆上的城門與窗戶、跨越護城河的木橋）
- 背景音樂為 Web Audio 即時生成；海浪、海鷗、挖沙音效來自 ElevenLabs
