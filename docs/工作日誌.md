# 工作日誌

每天收工時在**最上面**加一則：做了什麼、做到哪、待辦、決定與原因。架構與規則請看根目錄的 `AGENTS.md`。

## 2026-10-07

**完成（commit `08c16bf`，已推到 main）**
- 沙雕塊新增 12 種大型預設沙雕：海豚、女王頭像、城堡、趴著的貓、美人魚、海龜、章魚、螃蟹、海馬、睡獅、恐龍、海盜船。
  - 產製流程：Higgsfield 造型圖 → Hunyuan3D v3 geometry-only（每個 11 點，共 132 點）→ `tools/bake_sculptures.py` 烘焙成 `.sand`。
  - 放下後就是一般沙雕體素，可從正面、側面細修。
- 沙雕塊與裝飾的選擇視窗：選完會收成小標籤（`UI.showPicker`），不再遮住沙灘。點小標籤或再按一次工具鍵可以重開。
- 火把改成提基火把：竹竿貼圖、藤編火把頭、真實火焰照片配 shader 搖曳，光暈改成圓形漸層。
- 修正力道與大小面板的數字被擠出框外的問題（滑桿加 `min-width: 0`）。
- 工具說明列：使用者一度要求移除，後來改口保留。最終是預設顯示，並在設定加了「💬 顯示工具說明」開關（`save.settings.hints`）。
- 新增 `AGENTS.md`（給 AI 的交接文件）、`CLAUDE.md`（自動引用它）與本日誌。

**決定與原因**
- 預設沙雕用「圖 → 3D → 烘焙成體素」，不用程式手刻形狀：品質好很多，而且放下後可以照常雕刻。
- 火焰用照片加 shader 扭曲，不用生成序列幀：單張圖品質穩定，動態由 shader 做比較自然。

**待辦 / 可以接著做**
- README 的操作說明過時（還寫 1–9 切換工具），要依 `AGENTS.md` 更新。
- 沙雕不會被潮水侵蝕；蓋好的作品不會存檔。
- 放大型沙雕時會頓約 0.1～0.6 秒，必要時可以改成分幀網格化，並加「從沙裡升起」的動畫。
- `UNLOCK_ALL_LEVELS = true` 是測試設定，正式版要改回 false。
- 確認 Netlify 已部署最新的 main。
